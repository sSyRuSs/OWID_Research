# Papers and thesis

Each manuscript, its compiled PDF, and any paper-specific generated LaTeX tables
are kept together in their own folder:

| Folder | Work | Build inputs |
|---|---|---|
| `kmeans_owid_development/` | K-Means clustering of country development | Figures under `../../outputs/` |
| `carbon_intensity_ml_owid_2000_2025/` | Earlier carbon-intensity ML paper | Tables generated by `src/carbon_intensity_workflow.py`; figures under `../../outputs/carbon_intensity/` |
| `thesis_explainable_carbon_intensity/` | Explainable carbon-intensity thesis | Figures and tables under `../../outputs/thesis/` |
| `explainable_carbon_intensity_owid_2000_2025/` | Current research paper | Figures under `../../outputs/thesis/figures/` |

Build a document from its own folder so relative figure and table paths resolve.
The current paper's XeLaTeX/Tectonic instructions are in its local README.

Only generated compiler sidecars (such as `.aux`, `.log`, `.out`, `.toc`,
`.lof`, `.lot`, `.blg`, `.bbl`, and `.synctex.gz`) are disposable. Keep source `.tex`,
references, paper-specific generated tables, and PDFs.
